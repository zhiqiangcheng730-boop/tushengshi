## 1. 产品背景与目标

### 1.1 背景

用户在报名、学习、办公和日常生活中，经常需要处理照片、扫描纸质材料、复制图片文字、翻译图片内容或理解物品说明。相关能力分散在多个应用中，存在切换频繁、操作步骤多、文件导出不便等使用成本。

本产品将上述任务整合到一个移动 App，以相机、相册和文件选择为共同入口，让用户完成从输入材料到获得可用结果的完整流程。

市场选择依据以公开应用商店的产品功能、评分规模和累计下载为参考。相关数据是整个产品的累计表现，不能直接代表某项功能的使用频率、日活或付费转化。资料见第 15 节。

### 1.2 产品目标

1. 用户可以自行完成证件照换底色、改规格和报名文件大小处理。
2. 用户可以将纸质材料转换为清晰的图片、可复制文字或多页 PDF。
3. 用户可以完成常见图片压缩、裁剪、拼接、打码和背景处理。
4. 用户可以通过拍照或选择截图完成中英翻译和针对图片的问答。
5. 基础图片处理优先在手机本地运行；AI 功能通过可替换的能力接口接入。
6. 后续手机端离线推理作为独立验证阶段，保留明确的演进路径。

### 1.3 首版成功标准

- 五个入口均能完成“输入 → 处理 → 预览/修改 → 保存/分享”的闭环。
- 证件照、扫描成 PDF、图片基础处理在断网状态下可完成。
- OCR 文字提取以手机本地运行为首版工程默认建议，需在平台选定后验证。
- AI 服务未配置、断开或不可用时，基础工具仍能正常使用。
- 所有首版 P0 需求通过验收，不存在丢失原图、输出文件损坏或静默上传的问题。
- 用户能看清输出结果的像素尺寸、文件大小和保存状态。

## 4. 信息结构与统一流程

### 4.1 页面结构

| 页面 | 必需内容 |
|---|---|
| 首页 | 五个功能入口、最近处理记录 |
| 图片输入页 | 拍照、从相册选择、从文件选择；支持的类型与数量提示 |
| 处理与编辑页 | 当前材料、功能参数、预览、撤销/重做、开始处理 |
| 结果页 | 结果预览、继续修改、输出信息、保存、分享 |
| 历史记录页 | 任务类型、时间、缩略图/摘要、处理结果、打开、删除 |
| 设置页 | AI 连接方式、连接状态、缓存与记录管理、权限说明、版本信息 |

页面中的主要按钮表达用户动作，例如“换底色”“提取文字”“保存 PDF”。模型名称、推理引擎、量化参数等配置集中在设置或开发配置中。

### 4.2 统一主流程

1. 选择功能入口。
2. 拍照或选择已有图片。
3. 调整裁剪区域和功能参数。
4. 执行图片处理、OCR 或 AI 请求。
5. 预览结果；允许修改、重试或返回编辑。
6. 保存到相册/文件，或调用系统分享。
7. 记录处理结果与保存状态，方便再次打开。

### 4.3 任务状态

| 状态 | 含义 | 允许的后续动作 |
|---|---|---|
| 草稿 | 已选择材料，可修改参数 | 开始、移除材料、退出 |
| 处理中 | 本地处理或 AI 请求执行中 | 查看状态、取消 |
| 待确认 | 已生成结果，尚未确认保存 | 修改、重新处理、保存、分享 |
| 已保存 | 至少一份结果已成功写入目标位置 | 打开、分享、再次导出、删除应用内记录 |
| 失败 | 本次处理或保存失败 | 修改输入、重试、返回 |
| 已取消 | 用户取消本次处理 | 返回编辑、创建新任务 |

- 处理成功与保存成功分开标记。
- 分享操作不等同于文件已经保存。
- 取消、失败后不继续在后台自动保存或分享。
- 连续点击处理按钮不能产生重复任务或重复导出。

## 6. 首版模块需求

### 6.1 证件照

**使用目标：** 将拍照或已有照片处理成指定底色、尺寸和文件大小的电子照片，并支持打印排版。

| 需求编号 | 优先级 | 功能要求 | 验收条件 |
|---|---|---|---|
| ID-01 | P0 | 单人照片抠图；提供红、蓝、白底与自定义纯色；允许手动修边 | 前景保留，背景颜色与所选色一致；修边支持撤销/重做；多人照片先选择目标人物 |
| ID-02 | P0 | 提供一寸、二寸及自定义尺寸；支持拖动、缩放、旋转和裁剪 | 导出像素尺寸与参数一致；不通过拉伸改变人物比例；模板显示物理尺寸和像素尺寸 |
| ID-03 | P0 | 按目标文件大小导出并显示实际大小 | 输出满足所设上限时才标记达标；无法同时满足尺寸、格式和大小时说明原因并允许修改参数 |
| ID-04 | P0 | 提供电子照片与打印排版两种导出 | 电子照片可保存 JPG/PNG；打印排版可保存图片或 PDF，照片之间不重叠、不超出纸张边界 |
| ID-05 | P1 | 扩充考试、入学、签证等规格模板 | 每个模板有名称、尺寸、底色、来源/说明和维护日期，用户可以修改参数 |

模板建议基线：

| 模板 | 物理尺寸 | 300 DPI 下建议像素尺寸 |
|---|---|---|
| 一寸 | 25 × 35 mm | 295 × 413 px |
| 二寸 | 35 × 49 mm | 413 × 579 px |
| 自定义 | 用户填写宽高 | 按用户设置计算或直接输入像素 |

- 上表为产品默认模板，不代表各办事机构的全部要求；以用户收到的要求为准。
- 毫米换算像素采用：像素数 = round（毫米数 ÷ 25.4 × DPI）。
- 打印排版默认采用 4 × 6 英寸相纸，即 101.6 × 152.4 mm；300 DPI 对应 1200 × 1800 px。
- 排版 PDF 保留物理页面尺寸，并提示打印时选择实际尺寸。
- 首版不自动改变五官、生成服装或重绘人脸。
- “指定文件大小”复用 IMG-01 的压缩规则。

### 6.2 扫描识字

**使用目标：** 将纸质材料或截图转换为清晰扫描件、可编辑文字或多页 PDF。

| 需求编号 | 优先级 | 功能要求 | 验收条件 |
|---|---|---|---|
| SCAN-01 | P0 | 自动检测纸张边缘；允许手动调整四角、旋转、透视矫正；提供原色、增强、灰度/黑白预览 | 自动检测失败后仍能手动完成；文字主体不被裁掉；用户可切换处理效果 |
| SCAN-02 | P0 | 多页拍摄/选图，支持增删、排序、逐页编辑 | 建议基线范围 1–20 页；页面数量和顺序与最终 PDF 一致 |
| SCAN-03 | P0 | 导出扫描图片或多页 PDF | 文件可被系统预览和常见 PDF 阅读器打开；页面内容完整、方向正确 |
| OCR-01 | P0 | 提取简体中文、英文印刷体；允许框选识别区域 | 文字按合理阅读顺序输出；纯图片/无文字时不生成虚构文字；断网可执行本地 OCR |
| OCR-02 | P0 | 识别结果编辑、复制、保存 UTF-8 TXT；多页结果标记来源页 | 编辑后导出的内容与编辑框一致；页标记和正文可区分；字符编码正确 |
| OCR-03 | P1 | 将识别文字交给 Qwen 生成摘要或整理要点 | 原文保留；用户主动触发；明确区分识别原文和生成内容 |

范围边界：

- 首版 PDF 是由扫描图片组成的文件；可搜索文本层列为 P1。
- 首版不承诺手写体、复杂表格、公式和艺术字体的准确识别。
- 不包含 PDF 转 Word/Excel/PPT、复杂版面还原或完整 PDF 编辑器。
- 仅有本地 OCR 时也能完成扫描识字入口，不依赖 Qwen。
- 去阴影和增强不能静默删去文字；处理后提供原图对照和回退。

### 6.3 图片工具

**使用目标：** 完成图片上传、分享和简单制作所需的常用处理。

| 需求编号 | 优先级 | 功能要求 | 验收条件 |
|---|---|---|---|
| IMG-01 | P0 | 按最大文件大小压缩；支持 50/100/200/500 KB 预设；自定义上限建议为 5–20480 KB | 显示处理前后大小；实际输出字节数不大于目标时才标记达标；保持或改变尺寸由用户选择 |
| IMG-02 | P0 | 修改尺寸、裁剪比例、旋转和 JPG/PNG 转换 | 导出尺寸、方向和格式与参数一致；保持比例默认开启；透明图转 JPG 前选择填充底色 |
| IMG-03 | P0 | 照片拼图及长截图拼接；调整排列、间距、边距、裁剪和重叠区域 | 拼图建议基线 2–9 张；长截图 2–6 张；输出顺序与预览一致，无额外空白或丢失选定内容 |
| IMG-04 | P0 | 手动框选/涂抹马赛克及实色遮盖，支持撤销/重做 | 遮盖位置与预览一致；导出图片已合成遮盖，不包含可关闭的原图图层 |
| IMG-05 | P0 | 人物或单个主要物品抠图；透明底、纯色底和自选背景；允许修边 | PNG 可保留透明度；换背景后主体比例与定位一致；复杂边缘可通过手动编辑补救 |
| IMG-06 | P1 | 自动拼接截图、识别手机号/地址/人脸并建议打码、批量处理 | 用户可调整建议；未确认前不自动导出；自动失败时仍可使用手动功能 |

压缩与尺寸规则：

1. 本 App 的 KB 按 1024 字节计算，用户输入界面和结果页使用同一单位。
2. 自定义大小必须落在界面标明的有效范围内；初始建议范围为 5–20480 KB。
3. 不允许导出超过上限的文件后仍显示“符合要求”。
4. 若仅调整压缩质量无法满足目标，提示用户改格式、降低尺寸或放宽上限。
5. 证件照已指定像素尺寸时，不得为了满足大小自动更改尺寸。
6. 透明背景、尺寸和文件大小发生冲突时，说明取舍，由用户调整。
7. 极端压缩结果仍须提供放大预览，便于检查文字和人像是否可用。
8. 基础图片导出建议限制宽、高各为 1–20000 px，且总像素不超过 2000 万；超限时由用户确认降低整体分辨率或拆分处理，不自动截掉内容。该边界包括拼图与长截图，需在 M0 校准。

### 6.4 拍照翻译

**使用目标：** 从照片或截图获取原文，并得到可对照、可修改、可复制的译文。

| 需求编号 | 优先级 | 功能要求 | 验收条件 |
|---|---|---|---|
| TRANS-01 | P0 | 选择图片或拍照，框选文字区域；提取原文并允许修改；选择源语言和目标语言 | 中英双向可完成；自动语言判断失败时允许手动选择；修改原文后旧译文标记为需要重新生成 |
| TRANS-02 | P0 | 调用 AI 翻译；原文与译文对照；复制或导出 TXT | 两者清楚区分；导出采用用户最终确认的文本；保存结果包含语言信息 |
| TRANS-03 | P0 | 对无文字、识别失败、服务中断和超长文本提供处理路径 | 无文字不请求翻译；失败可重试或编辑原文；超长输入提示分段，不静默截断 |
| TRANS-04 | P1 | 增加日语、韩语等语言及复杂排版翻译 | 每种新增语言单独验证；不以模型支持语言数直接替代实际验收 |

- 首版采用图片预览加原文/译文文本对照。
- 原版面覆盖译文、AR 实时翻译、复杂表格原样翻译不属于 P0。
- 翻译服务只需原文时，仅发送所选文本；确需图片理解时才发送所选图片。
- Qwen 负责翻译和内容解释，OCR 负责原文提取。

### 6.5 拍照问答

**使用目标：** 用户围绕一张图片提出问题，获得针对当前图片的解释，并继续追问。

| 需求编号 | 优先级 | 功能要求 | 验收条件 |
|---|---|---|---|
| ASK-01 | P0 | 拍照或选择单张图片，支持“描述图片”“这是什么”“解释文字/标签”等快捷问题和自定义问题 | 请求包含当前图片和问题；回答与图片内容相关；未选图片时引导先选择 |
| ASK-02 | P0 | 同一图片支持连续追问；可复制和保存对话 | 建议基线连续 5 轮可用；更换图片后创建新上下文，避免混入旧图信息 |
| ASK-03 | P0 | 信息不足或图片不清晰时说明无法确认，并提示补拍或补充信息 | 不将不可见文字、具体型号或品牌编造成确定事实；用户可裁剪、重拍或补充文字 |
| ASK-04 | P0 | 显示等待、取消、超时和重试状态 | 取消后不继续追加回答；连接恢复后可手动重试；不会把部分回答显示为完整结果 |
| ASK-05 | P1 | 支持多图对比和更丰富的快捷任务 | 另行定义图片数量、资源边界和验收样本后交付 |

首版验证场景：常见生活物品、家电按钮/面板、洗衣标签、商品标签、图中说明文字与简单生活场景。

本期不提供联网商品比价、精确商品数据库查询或替用户操作其他 App。仅凭图片不能确认的信息，不承诺给出精确结论。

## 7. AI 连接与部署要求

### 7.1 前期：电脑本地模型服务

| 需求编号 | 优先级 | 要求 | 验收条件 |
|---|---|---|---|
| AI-01 | P0 | 设置页允许配置模型服务地址、必要凭证、连接检测及请求超时 | 可连接性有明确反馈；地址/凭证错误有提示；凭证不写入普通日志 |
| AI-02 | P0 | 图像问答链路接入具备图像输入能力的 Qwen3.5 4B 部署 | 真实手机选图后能获得回答；同时验证图像预处理、视觉组件、模型版本与接口兼容性 |
| AI-03 | P0 | 区分文本翻译请求和图像问答请求；仅发送本次任务必要内容 | 不上传整个相册；处理参数明确；失败后由用户决定重试 |
| AI-04 | P0 | 为服务端推理和未来端侧推理保留统一调用边界 | 上层功能可表达翻译、图像问答、取消、超时和错误；不把服务器部署细节写入各业务页面 |
| AI-05 | P0 | 模型不可用时清楚显示当前能力状态 | 不显示虚构回答；不擅自切换到未配置的第三方服务 |

- “本地模型”在本阶段指电脑上的自建模型服务，手机仍需能够连接该服务。
- 局域网服务用于开发验证；离开该网络后能否访问，由实际网络与服务部署决定。
- 连接配置要使用手机可访问的服务地址，不能把电脑上的 localhost 当作手机可访问地址。
- 连接测试成功不能替代图像端到端测试；仅文字对话成功也不能代表图像链路成功。
- 发布环境的模型通信采用加密传输；局域网开发模式的例外需要独立配置。
- 内置示例图必须标注为示例，不能伪装成实时模型结果。

### 7.2 后期：手机端离线模型包

| 需求编号 | 优先级 | 要求 | 阶段验收条件 |
|---|---|---|---|
| EDGE-01 | P2 | 集成移动端推理引擎及经过适配的模型 | 在明确的目标设备上支持所需文本/图像输入，完成真实离线问答 |
| EDGE-02 | P2 | 支持可选模型包安装、校验、升级和删除 | 显示下载/安装体积；校验失败不启用；删除模型不删除用户结果 |
| EDGE-03 | P2 | 评估内存、响应时间、发热、电量、包体和存储 | 给出真实测试报告，明确支持设备范围与降级路径 |
| EDGE-04 | P2 | 端侧资源不足或不支持时保持 App 基础工具可用 | 明确提示；不自动下载其他模型或切换到第三方服务 |

- App 安装包可运行与大模型可在手机离线运行是两项独立交付。
- 不能仅把电脑端模型权重复制到 App 中就视为集成完成。
- 4bit 参数存储只能作为理论体积估算；实际还需考虑视觉组件、量化元数据和运行缓存。
- MNN 等移动端框架可列为候选，但具体模型格式、图像支持和设备表现需单独 POC。
- 首版发布不以端侧 Qwen3.5 4B 验证成功为前置条件。

## 8. 数据与文件管理要求

| 对象 | 最少信息 | 保存原则 |
|---|---|---|
| 输入材料 | 来源、访问引用、格式、方向、宽高、大小、选定区域 | 优先引用原图；任务所需临时副本仅留在应用私有空间 |
| 编辑参数 | 模块、底色、裁剪、尺寸、压缩上限、拼接顺序等 | 与任务绑定，方便修改和再次导出 |
| 任务记录 | 任务标识、功能、创建时间、状态、错误摘要 | 保存在本地，不记录凭证 |
| 输出结果 | 类型、保存位置/引用、大小、尺寸/页数、生成时间 | 清楚区分应用内结果与外部导出副本 |
| 文字结果 | OCR 原文、用户修改稿、译文、语言信息 | 编辑与生成结果分开保存 |
| 问答记录 | 所选图片引用、问题、回答、完成状态、执行方式 | 仅保存本任务内容，允许删除 |
| AI 配置 | 地址、必要凭证、能力、超时、连接状态 | 凭证采用系统安全存储能力，不混入普通记录 |

- 不覆盖、移动或删除系统相册中的原始照片。
- 删除历史默认仅删除对应应用内记录及其专属缓存/副本。
- 同一个应用内文件被多个任务引用时，不因删除其中一个任务而破坏其他任务。
- 导出到相册或文件目录的副本，后续由用户在对应位置管理。
- 临时文件在取消或失败后清理；成功结果可由用户保留或删除。
- 原图授权失效、原图被移动或删除时，允许重选材料，并说明不可恢复的编辑内容。
- 记录管理页显示应用内占用空间，支持按任务删除和清理临时缓存。
- 不将用户图片用于训练，不默认上传日志中的原图或完整对话。

### 9.2 建议性能与质量验收目标

以下目标需在 M0 阶段经 POC 校准后冻结。参考机型未定前，不承诺所有手机均满足同一耗时。

| 项目 | 建议目标 | 固定测试条件 |
|---|---|---|
| 单张图片基础处理 | P95 完成时间不超过 3 秒 | 参考手机，4000 × 3000 JPG；压缩、裁剪、打码分别统计 |
| 单张抠图 | P95 完成时间不超过 5 秒 | 参考手机，限制模型输入分辨率；记录导出分辨率 |
| 单页 OCR | P95 完成时间不超过 5 秒 | 参考手机，清晰 A4 材料，中文/英文分别记录 |
| 20 页 PDF 生成 | 不丢页、不乱序、可打开；时间和峰值内存纳入测试报告 | 每页约 1200万像素来源图，允许逐页缩放后生成 |
| AI 请求等待反馈 | 1 秒内进入等待状态；默认总超时建议 120 秒，可配置 | 同时记录首段输出时间与最终完成时间；不得用界面反馈代替推理性能 |
| OCR 清晰印刷体 | 字符错误率 CER 不超过 2% | 固定标注文本；统一换行/空白规则，保留文字、数字和标点 |
| OCR 日常拍摄印刷体 | CER 不超过 5% | 正常光照、可读文字；倾斜校正后识别 |
| 抠图质量 | 固定简单场景集平均前景 IoU 不低于 0.90；人像脸部不得发生明显误删 | 30 张单人像、20 张单主体物品；有人工标注及人工复核 |
| 翻译质量 | 至少 90% 样本保留关键含义且无新增事实 | 固定 50 段中英材料；人工对照审查，包含数字、日期和否定语句 |
| 图片问答质量 | 可回答样本关键事实正确率建议不低于 90%；信息不足样本应明确无法确认 | 40 个可回答、10 个信息不足的固定图文问题；按标准答案人工复核 |

补充规则：

- P95 指至少 95% 测试任务的完成时间不超过该数值。
- CER 按替换、删除、插入字符数除以参考字符数计算，不用模型自评替代标注对照。
- IoU 用人工前景标注计算，不能只以“看起来不错”替代。
- 质量目标用于界定验证标准，不代表任意图片都能正确处理。
- 如 POC 不达标，先调整输入边界、模型/算法和产品流程，再冻结验收目标，不静默降低标准。

## 10. 异常与降级流程

| 情况 | 产品行为 | 恢复路径 |
|---|---|---|
| 相机权限被拒绝 | 说明拍照暂不可用，其他入口可继续使用 | 选择已有图片或打开系统设置 |
| 相册访问受限 | 显示可访问图片范围 | 使用系统选择器增加图片或从文件导入 |
| 相册写入被拒绝 | 保留当前结果，不显示保存成功 | 导出到文件或调用系统分享 |
| 图片损坏、不支持或超限 | 不启动处理，提示具体原因 | 换图、缩小图片或减少数量 |
| 多人照片用于证件照 | 提示选择目标人物/裁剪区域 | 手动选择后继续 |
| 无法检测纸张 | 保留原图并进入手动裁边 | 调整四角或重新拍摄 |
| 无文字或文字不可读 | 显示未识别到可用文字 | 裁剪、重拍或手动输入 |
| 指定尺寸与文件大小无法同时满足 | 显示实际大小及未达标原因 | 改大小上限、格式或尺寸 |
| 存储不足/保存失败 | 不记录虚假的保存位置 | 清理空间、换目标位置、重试 |
| AI 未配置/连接失败 | 显示当前 AI 不可用，基础工具可继续使用 | 配置服务、检测连接、手动重试 |
| AI 超时或中途断开 | 保留已确认的原文/问题；部分回答标记未完成 | 用户决定重试或返回 |
| 用户取消后晚到的模型响应 | 丢弃该任务的后续输出 | 返回编辑，不自动保存 |
| 原图引用失效 | 显示原材料不可用 | 重选图片；已有导出结果仍可打开 |
| App 被中断或系统回收 | 恢复已保存的任务参数和已完成结果；不虚构处理完成状态 | 重新执行未完成部分或从已完成页面继续 |

2. 五个入口各至少完成一次真实设备的保存与分享闭环。
3. 功能可用性、性能和模型质量分别报告，不能互相替代。
4. 导出文件可被系统预览及至少一种常见外部应用打开。
5. 基础离线流程通过；AI 服务不可用时具备明确恢复路径。
6. 端侧模型 POC 结果不作为本阶段发布门槛。

## 12. 交付阶段与里程碑

| 里程碑 | 交付范围 | 退出条件 |
|---|---|---|
| M0：验证基线 | 选定首发平台/参考设备；本地 OCR、抠图及 Qwen 视觉接口 POC；建立固定测试集 | 输入边界、性能/质量目标和组件能力有验证结论 |
| M1：基础闭环 | 通用输入、预览、导出、历史；证件照、扫描识字、图片工具 | 对应 P0 用例通过，断网可用 |
| M2：AI 闭环 | AI 配置、拍照翻译、拍照问答、取消/超时/降级 | 真实手机调用真实模型完成问答与翻译 |
| M3：首版打包交付 | 安装包、使用说明、测试报告、已知问题、版本说明 | 首发平台可安装；P0 门槛全部满足 |
| M4：后续端侧验证 | 推理引擎、可选离线模型包、设备适配报告 | 单独通过 EDGE-01 至 EDGE-04，明确支持范围后决定发布 |

本需求文档不预设工期和费用。排期在平台、组件验证与人员配置明确后制定。

## 13. 后续需求池与范围边界

| 功能 | 优先级 | 后续细化方向 |
|---|---|---|
| 水印相机 | P2，优先评估 | 时间、地点、文字备注、自定义模板；根据工作用户需求决定先后 |
| 相册整理 | P2 | 重复/相似照片、截图筛选、空间排序；用户确认后清理 |
| 图片消除与画质修复 | P2 | 独立选择图像模型，验证资源和效果 |
| 端侧 Qwen 离线模型包 | P2 | 见第 7.2 节，独立验证与交付 |
| 截图转待办 | P3 | 信息提取、时间确认、本地提醒和用户留存验证 |
| 小票记账 | P3 | 金额/日期确认、分类、账本与导出 |
| 食品日期提醒 | P3 | 包装日期提取、日期规则确认、提醒使用率 |
| 家庭物品档案 | P3 | 购买凭证、保修日期、物品位置与检索 |

当前 P0 范围不包括：

- 账号体系、云同步、付费订阅、广告、团队协作。
- 完整美颜相机、AI 写真、视频剪辑和视频生成。
- 通用知识聊天、联网比价、商品数据库或跨 App 自动操作。
- 完整 Office/PDF 编辑器及复杂版面转换。
- 自动删除系统相册照片。
- 未经目标设备验证就承诺 Qwen3.5 4B 可在所有手机离线流畅运行。

后续增加范围时，同步修改需求版本、验收清单和里程碑，避免增强项变成隐含首版承诺。
