# 数得快 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. 本文件为待评审计划，所有任务均未执行；本次仅制作设计文档与 HTML。

**Goal:** 实现店员可复核、可恢复、可留档的拍照数签闭环，并完成 Qwen POC 与上线前 VLX 验证。

**Architecture:** FastAPI 模块化业务单体，PostgreSQL 事务与持久任务，独立推理 worker。小程序只持有草稿与交互状态，最终数量及签费由服务端校验、确认和冻结。

**Tech Stack:** 原生小程序／TypeScript、Python／FastAPI、PostgreSQL／SQLAlchemy、MLX-VLM、VLX-Seek。

**Spec:** [产品需求](01-产品需求与交互设计.md)、[架构契约](03-架构与技术方案.md)、[测试计划](06-测试与验收计划.md)。

## Global Constraints

- 前期使用 Qwen3-VL-2B（MLX 4bit）；上线前使用 VLX-Seek 1.5-10B；200 区域扩容后置。
- 精准要求 98%，统计口径待确认，正式验收前必须冻结。
- 价格开单快照、整数分；完成快照不可修改；未处理批次禁止完成。
- 重拍同 batch_id 追加修订；旧结果不能覆盖新版本；业务命令幂等。
- 门店权限服务端校验；同单当前经办人编辑；原图与诊断输出不写普通日志。
- 本文业务路径均为计划新增；不假设已经存在代码、模型环境或真实测试集。

## Review Focus

1. 相同实物的不同角度照片不能靠请求幂等识别，T05／T23 验证现场分区与店员理解。
2. 人工数量与点位数量不一致时必须保留来源，T11／T14 测试手工分支。
3. 相机、相册、旋转与留白缩放组合时点位必须对齐，T09／T14 测试逆变换。
4. worker 重启／租约过期／用户已改数后迟到结果不得覆盖，T10／T16／T20 测试。
5. 更正草稿取消、失败或并发完成不能使旧单提前失效，T12／T20 测试原子替换。
